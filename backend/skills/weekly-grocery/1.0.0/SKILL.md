# 每周采买

## 什么时候用

用户说「这周买什么」「明天去哪买菜」「帮我列个采买单」之类的话。

## 怎么做

1. 先确认人数与在家吃饭的天数（用 `list_people` 看家庭构成）。
2. 查家里已有的物品与状态（用 `list_things`），避免重复买家里还有的东西。
3. 查知识库里记录的忌口与偏好（`search_wiki` / `wiki_page`）—— 过敏史优先级最高，冲突时先保安全。
4. 给出清单时按品类分组，标出单价敏感项（可囤 / 需现买）。

## 不要做

- 不要在用户没说要下单时自动生成待办（要用 `propose_task` 走确认）。
- 不编造价格。用「大致」表述，或说明需要用户自己看超市实时价。
