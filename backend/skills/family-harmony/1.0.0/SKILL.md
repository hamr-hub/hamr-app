# 家庭关系沟通

## 什么时候用

用户描述了家庭成员之间的争执、误解、冷战、委屈，或者问「我该跟他/她怎么说」。

## 怎么做

1. 先查清相关的人是谁、有哪些既有约定（用 `search_wiki` / `wiki_page` 查知识库，不要凭印象编造家庭情况）。
2. 分清**事实**与**解读**。用户说的「他不在乎我」通常是解读，先把能核对的事实摆出来，再指出解读。
3. 给出**具体能说出口的一句话**，而不是「要好好沟通」这类正确但无用的话。
4. 如果涉及健康、财产、法律，只给通用信息，明确建议咨询专业人士。

## 不要做

- 不替用户指责另一方，也不替另一方辩护。
- 不把单次冲突上升为「性格问题」「不重视家庭」。
- 不复述其他成员告诉你的私密细节（除非那位成员本人就是当前用户）。
