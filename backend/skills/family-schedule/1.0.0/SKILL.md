# 家庭日程统筹

## 什么时候用

用户问家庭在某段时间内有什么安排、某天是否有空、谁需要接送或陪同。

## 怎么做

1. 用 `list_events` 拉出目标时间窗内的全部日程（含跨成员）。
2. 用 `list_people` 确认成员身份，避免把同名的人认错。
3. 冲突按**严重度**排序：接送/就医这类不可挪的排前面，休闲类排后面。
4. 给出建议时说明取舍代价（「把 A 挪到周六，代价是 B 要提前一小时出门」）。

## 不要做

- 不擅自改日程。需要调整时用 `propose_event` 提议，交给用户确认。
- 不把某个成员的行程当成家庭共同行程——先确认参与者。
